# Tassawaq API

A modern, scalable, and production-ready E-Commerce REST API built with **Node.js**, **Express.js**, and **MongoDB** following software engineering best practices and clean architecture principles.

> **Project Status:** Under Development

---

# About

Tassawaq is a backend-focused e-commerce project designed to simulate a real-world production system.

The project is being developed step by step following the complete Software Development Life Cycle (SDLC), from planning and analysis to deployment.

The primary goal is to build a scalable REST API while applying industry best practices in backend development.

# Development Workflow

This project follows a feature-based development workflow.

Each feature is implemented in its own Git branch before being merged into the `main` branch.

Example:

```text
main
│
├── feature/database-design
├── feature/project-setup
├── feature/authentication
├── feature/products
├── feature/orders
└── ...
```
