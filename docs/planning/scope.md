# Project Scope

## In Scope (MVP)

- User Authentication
- User Profile
- Product Management
- Categories
- Brands
- Shopping Cart
- Wishlist
- Orders
- Coupons
- Payments
- Reviews
- Notifications
- Admin Dashboard

---

## Out of Scope

The following features are not included in the first release:

- Product recommendations
- AI-powered search
- Live chat
- Multi-language support
- Multi-vendor marketplace
- Loyalty points
- Social login
- Product comparison
- Analytics dashboard
