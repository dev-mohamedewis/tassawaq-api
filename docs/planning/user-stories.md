# User Stories

## Authentication

- As a guest, I want to create an account so that I can place orders.
- As a user, I want to log in so that I can access my account.
- As a user, I want to reset my password so that I can recover my account.

---

## Products

- As a guest, I want to browse products so that I can explore available items.
- As a guest, I want to search for products so that I can quickly find what I need.

---

## Cart

- As a user, I want to add products to my cart so that I can purchase them later.

---

## Orders

- As a user, I want to place an order so that I can buy products.
- As a user, I want to view my order history so that I can track previous purchases.

---

## Reviews

- As a user, I want to review purchased products so that I can share my experience.
